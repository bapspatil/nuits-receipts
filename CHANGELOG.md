## 1.0.1 (2026-10-23)

First public release. Earlier development history is not part of this repository.

### Features

- Self-hosted receipt and invoice reader that runs on Cloudflare Workers: PDF and image uploads, optional email ingestion with an allowlist and SPF check, private R2 storage of originals, D1 storage of extracted rows.
- Extraction with Cloudflare's Clairic model on Workers AI (preview), VAT arithmetic checked in code, review flags for uncertain rows.
- Vendor rules with a Clef fallback for product and expense type.
- Bank CSV import with a column mapping, payment matching suggestions and a list of payments with no receipt.
- Monthly package: costs in EUR by product and type, CSV or ZIP with every original and an index spreadsheet, optional OneDrive upload.
- Sales invoices you send, matched to money coming in.
- In-app settings, Cloudflare Access sign-in, compact mobile layout with a bottom tab bar.
- Project site in site/ with a demo video, and a documentation site in docs-site/.
