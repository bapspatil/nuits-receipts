## 1.3.0 (2026-10-24)

### UI enhancements

- One app shell, quiet statuses and a one-line footer notice on every page.
- Home shows the month as three steps (Check, Match, Send). Review is a plain list, and the receipt page puts the fields to fix first.
- Receipts, Invoices and Bank are quiet lists with one search field and one More menu per row. Statements are folded.
- Settings has one fold per section and an About section with the full notice, licence and trademark lines. The docs match the new screens.
- Much less text on every page.

## 1.0.2 (2026-10-23)

### Fixes

- Settings: a list of allowed senders is limited to 75 addresses, so the longest list always fits the stored-setting limit. A value that is too long is refused with a clear message instead of failing on save.
- Month package: the "changes" package no longer replaces the full month index.
- Bank matching: a seller name that reduces to nothing never matches a payment.
- The app has a tab icon.

### Documentation and project site

- The docs changelog no longer links to commits that are not in this repository.
- The docs site sends security headers, including a Content-Security-Policy.
- The phone tab bar and the More page are documented, and the deploy tutorial lists the right navigation.
- The project site has a Docs link, a 404 page and a sitemap.

## 1.0.1 (2026-10-23)

First public release. Earlier development history is not part of this repository.

### Features

- Self-hosted receipt and invoice reader that runs on Cloudflare Workers: PDF and image uploads, optional email ingestion with an allowlist and SPF check, private R2 storage of originals, D1 storage of extracted rows.
