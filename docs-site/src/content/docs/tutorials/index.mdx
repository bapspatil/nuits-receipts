Tutorials are lessons for your first time with Nuits Receipts. Follow each one from top to bottom; every step shows you something on screen, and you finish with a result you can see.

<CardGrid>
  <Card title="Deploy your own copy" href="/tutorials/deploy-your-own-copy/">Deploy the app into your Cloudflare account with the Deploy to Cloudflare link, set your password and sign in.</Card>
  <Card title="Your first month" href="/tutorials/your-first-month/">Upload sample receipts, approve them, import a sample bank statement, see the match and send the month.</Card>
  <Card title="Run it locally" href="/tutorials/run-it-locally/">For contributors: clone the code, run the app on your machine with test data, and run the tests.</Card>
</CardGrid>

Already know your way around? The [how-to guides](/how-to/) cover single tasks, and the [reference](/reference/) lists every setting and limit.
