Press `?` on any page to open the **Keyboard shortcuts** sheet. **Help** lists the same keys under **Keyboard**, at `/help#keyboard`. Both print one table in `src/keys.ts`, and the tables below follow it.

The keys are off while you type in a field, and on a phone or tablet. They are also off while a dialog, such as quick find or the `?` sheet, is open. `Esc` closes the sheet.

## On a list

| Keys | What it does |
| --- | --- |
| `j` or `k` | Move to the next or the previous row |
| `x` | Select or unselect the row you are on |
| `Enter` | Open the row you are on |

`j`, `k` and `Enter` move between and open the rows of the two work lists, Receipts To do and Bank. `x` works on any list with tick boxes while the focus is in a row. Three more keys work on those lists:

| Keys | What it does |
| --- | --- |
| Shift+`x` | Tick every row from the last one you ticked to this one |
| `Cmd+A` (`Ctrl+A` off a Mac) | Tick every row on the page |
| `Esc` | Clear the selection. With a step of the bar open, such as a reason, close that step first. |

See [Select several](/reference/app-pages/#select-several) for what each list can do with the ticked rows.

## On a receipt

| Keys | What it does |
| --- | --- |
| `a` | Approve |
| `s` | Skip |

`a` and `s` press **Approve receipt** (**Approve invoice** on a sales invoice) and **Skip** in the bar at the bottom of a receipt that needs you. They do nothing when that bar is not shown.

## On a PDF or a picture

| Keys | What it does |
| --- | --- |
| `+` or `-` | Zoom in or out |
| `0` | Fit to the width |
| `r` | Turn a quarter |
| `n` or `p` | Go to the next or the previous page |
| `f` | Find in the PDF |

These act on the first viewer on the page. See [PDF viewer](/reference/pdf-viewer/#keys).

## Everywhere

| Keys | What it does |
| --- | --- |
| `u` | Undo, when the message at the top offers it |
| `Cmd+K` (`Ctrl+K` off a Mac) | Find a file, on any page |
| `/` | Search: the page's own field, or find a file |
| `?` | Show these shortcuts |
| `Esc` | Close the shortcuts sheet |

`/` puts the cursor in the page's search field when the page shows one, such as Home's. On a page without one, it opens quick find, the same as `Cmd+K`.
