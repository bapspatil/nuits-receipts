Paths are relative to the app's root. With `APP_BASE_PATH` set (for example `/app`), every path starts with that prefix. Every page needs sign-in. Where a page takes `month`, the value is `YYYY-MM` and defaults to the current month (UTC).

## Main navigation

Every page has the same five links, in this order. On a wide screen (880 pixels or more) they are in the header. On a narrow screen they are in a tab bar fixed to the bottom of the screen, each with an icon. The link for the page you are on is marked. The tab bar hides while you type in a field, so it does not cover the keyboard.

| Link | Path | Badge | Marked on |
| --- | --- | --- | --- |
| Home | `/` | | Home |
| Review | `/review` | Number of documents and Unknown sender emails waiting | Review, and a document that needs review |
| Receipts | `/receipts` | | All receipts, Invoices you sent, Add, and a document that does not need review |
| Bank | `/payments` | Number of payments missing a receipt | Bank and the bank statement import |
| Settings | `/settings` | | Settings |

In Access mode the header also shows **Sign out**, which goes to `/cdn-cgi/access/logout`. On a phone, **Sign out** is at the top of **Settings**.

**Receipts** has two views at the top: **All receipts** (`/receipts`) and **Invoices you sent** (`/invoices`). **Invoices you sent** appears once `INVOICES_ADDRESS` is set or at least one sales invoice exists; `/invoices` works either way.

## Pages

| Path | Page title | Query parameters | What it shows |
| --- | --- | --- | --- |
| `/` | Home | `month`, `offset`, `anyway`, `undated`, `changes`, `sent`, `upload`, `wait` | On first run, "Welcome" with an upload form. Otherwise the month, with the three steps to close it: **Check receipts**, **Match payments** (with likely matches to confirm), **Send to `<ACCOUNTANT_LABEL>`**. Overdue invoices and emails from addresses that could not be verified show above the steps. Then "Money in: invoices dated `<month>`" when there are sales invoices, and "Receipts dated `<month>`". |
| `/month` | | any | Redirects (temporarily, 302) to `/` with the same query string. |
| `/more` | | | Redirects (temporarily, 302) to `/settings`. |
| `/review` | Review | `reason`: `info`, `amount` or `sender`; `approved`, `ignored`, `deleted` (result banners) | **Unknown senders** first: mail from senders not on your list, each with **Approve sender**, **Ignore sender** and **Delete**. Then documents with status `needs_review`, filtered by **Missing info**, **Check the amount** or **Email not verified**. Documents still being read are counted in a banner. |
| `/receipts` | All receipts | `show`: `ready`, `reading`, `duplicate` or `sales` (offered as filters), also `needs` and `unknown`; `month` (month received); `q` (search seller, client, file name, invoice number, sender or subject); `offset` | Every receipt, sales invoice and Unknown sender email, newest received first, 50 per page. A link counts what is waiting in Review, and **Add receipts** opens `/add`. Each row shows its status and links to the document (or to Review for Unknown sender). On the first page, **Recent mail** lists the last 20 emails that reached the app and what happened to each. With nothing yet, the receipt address to forward to. |
| `/receipts/<id>` | The document's seller or file name | | The original (image preview, or a link to the PDF or email) beside the form: review flag cards, all fields, part of the business and kind of cost, due date, euro amount, duplicate choice, **Note for your accountant** and the approve, save and **Read it again** buttons. Also bank match suggestions and a form to add a vendor rule. Sales invoices also show **Move to receipts** and the paid-outside form. |
| `/add` | Add documents | `kind`: `sales`; `added`, `failed` (result counts) | Upload of up to 10 files at once, as **Receipts and bills** or sales invoices, and the email addresses to forward to. |
| `/payments` | Bank: payments for `<month>` | `month`, `offset`, `show`: `missing`; `inserted`, `skipped`, `replayed` (import result) | Bank rows booked in the month from completed imports, 100 per page: matches, suggestions, payments with no receipt, exemption controls (**Not a purchase (no receipt needed)**, **Needs a receipt after all**) and own-account transfers. Once any statement is imported, also **Transfers** (`#transfers`: pairs, **Pair a transfer**, **Undo transfer**) and **Statements imported** (`#imports`: date, account and row count). |
| `/import` | Import a bank statement | | Step 1 of the [bank CSV import](/reference/bank-csv-import/): file, account and encoding. |
| `/imports/csv`, `/imports/csv/preview` (POST) | Check the file | | Step 2 of the import: rows read, problems, mapping editor and the import button. |
| `/invoices` | Invoices you sent, `<month>` | `month`, `show`: `all`, `review`, `unpaid`, `overdue`, `paid` | Sales invoices dated in the month with totals invoiced and received. `unpaid` and `overdue` list invoices from every month. |
| `/settings` | Settings | `onedrive`, `saved`, `reset`, `routing`, `rules` (result banners) | Sections listed below. |

### Settings sections

In page order. Each links from the side menu.

| Section | Anchor | Contains |
| --- | --- | --- |
| Business | `#setup-business` | App name, business names, parts of the business, default part, payment terms, new account currency. |
| Email | `#setup-email` | Receipt address, invoice address, allowed senders, forward copy address. |
| Senders | `#senders` | Approved senders (those from the deploy value marked **Default**) with **Remove**, **Add a sender**, and ignored senders with **Stop ignoring**. |
| Bank accounts | `#accounts` | Accounts with bank, currency and ID; rename; **Add a bank account**. Notes at `#imports` and `#transfers` point to **Bank**, where those moved. |
| Vendor rules | `#rules` | Rules with seller text, part of the business, kind of cost, extra conditions and priority; **Edit**, **Delete rule** and **Add a rule**. |
| Export | `#setup-accountant` | Accountant, export file name, note under the month download. |
| OneDrive | `#onedrive` | Shown only when `MS_CLIENT_ID` is set. Connect or disconnect a Microsoft account, the redirect URI for Microsoft Entra, and the destination folder. |
| Advanced | `#advanced` | Review & matching thresholds, the source code link, **Set at deploy** (read-only deploy values) and **Change history** (the last 20 setting changes). |

Each setting shows where its value comes from: **App** (set here), **Deploy** (Worker variable) or **Default** (built in). See [Configuration](/reference/configuration/).

## Downloads

| Path | Query parameters | Returns |
| --- | --- | --- |
| `/export.csv` | `month` | [Receipts CSV](/reference/export-csv/) for the month. |
| `/export-sales.csv` | `month` | [Sales CSV](/reference/export-csv/#sales-csv-columns) for the month. |

## Form actions

Each form posts to one of these paths and then redirects (303).

| Path | Does | Goes back to |
| --- | --- | --- |
| `/accounts`, `/accounts/<id>` | Add or rename a bank account. | `/settings#accounts` |
| `/transfers`, `/transfers/<id>/undo` | Pair or undo an own-account transfer. | Bank for the month the money left, `#transfers` |
| `/rules` | Add a vendor rule. | The receipt it was made from, else `/settings#rules` |
| `/rules/<id>`, `/rules/<id>/delete` | Change or delete a vendor rule. Unknown IDs return 404; a rule with the same seller and context text returns 409. | `/settings#rules` |

## Sign-in and OneDrive routes

| Path | Purpose |
| --- | --- |
| `/settings/onedrive/connect` | Starts the Microsoft sign-in. |
| `/settings/onedrive/callback` | Microsoft returns here after sign-in. This is the redirect URI to register in Microsoft Entra, prefixed with the app's origin and `APP_BASE_PATH`. |

## Responses without sign-in

| Mode | Response |
| --- | --- |
| Password (HTTP Basic) | 401 with a `Basic` challenge whose realm is `APP_NAME`. Sign-in also fails over plain `http` except on `localhost`, `127.0.0.1` and `[::1]`. |
| Cloudflare Access | 403 "Sign in through Cloudflare Access to use this app." |

Every form post must carry an `Origin` header equal to the app's origin, or it is refused with 403. Unknown paths return 404.
