This page renders `CHANGELOG.md` from the repository. `scripts/version.mjs` generates the entries from Conventional Commits on every release. The first release run planted the `v0.1.0` baseline from `package.json`; entries start after it.

## 1.0.0 (2026-10-22)


First stable release. No code changes since 0.7.0.

- Receipts by email or upload, read with Workers AI and cross-checked by a deterministic parser
- Any-bank CSV matching with saved column mappings
- Month package ZIP for the accountant
- Sales invoices
- In-app settings
- Cloudflare Access sign-in
- Redesigned, consistent UI across the whole app
