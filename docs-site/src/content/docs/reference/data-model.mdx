The D1 schema for a new installation is in `schema/`, applied in file order by `bun run deploy` and `bun run migrate` with the ledger table `template_migrations`. `scripts/schema.test.ts` checks the tables, constraints, indexes, triggers and foreign keys.

| File | Adds |
| --- | --- |
| `schema/0001_template.sql` | `accounts`, `bank_presets`, `bank_transactions`, `fx_rates`, `imports`, `internal_transfers`, `receipts`, `vendor_rules`, indexes, triggers, seed rows |
| `schema/0002_month_package.sql` | `month_sends`, `onedrive_connection`, `onedrive_uploads` |
| `schema/0003_sales_invoices.sql` | Sales invoice columns on `receipts` |
| `schema/0004_settings.sql` | `settings`, `settings_audit` |
| `schema/0005_inbound_mail.sql` | `inbound_mail`, `ignored_senders` |

Conventions: money is an integer in minor units (`*_minor`). VAT rates are integers in hundredths of a percent (`*_bps`). Dates are `YYYY-MM-DD` text; timestamps are ISO 8601 text in UTC. JSON is stored as text in `*_json` columns.

## `receipts`

Receipts and sales invoices. One row per original file.

| Column | Type | Rules | Meaning |
| --- | --- | --- | --- |
| `id` | TEXT | Primary key | SHA-256 of the original file's bytes. |
| `original_key` | TEXT | Not null, unique | R2 key of the original. |
| `filename` | TEXT | Not null | File name as uploaded or attached, at most 200 characters. |
| `media_type` | TEXT | Not null | `application/pdf`, `image/png`, `image/jpeg`, `image/webp`, `text/html`, `text/plain` or `message/rfc822`. |
| `source` | TEXT | `email` or `upload` | How it arrived. |
| `email_key` | TEXT | | R2 key of the email it came in, if any. |
| `received_at` | TEXT | Not null | When it was stored. |
| `status` | TEXT | `pending`, `processing`, `ready`, `needs_review` | See [statuses](/reference/receipt-fields-and-flags/#statuses). |
| `attempt_id` | TEXT | | ID of the read that holds the lease. |
| `lease_until` | TEXT | | End of the read lease. |
| `revision` | INTEGER | Default 0 | Raised on each saved correction or kind change. Guards against stale writes. |
| `vendor`, `invoice_number`, `issue_date`, `due_date`, `currency` | TEXT | | Read or corrected facts. |
| `total_minor`, `net_minor`, `vat_minor` | INTEGER | | Amounts. |
| `vat_rate_bps` | INTEGER | | VAT rate. |
| `line_items_json` | TEXT | | Descriptions read from the document. |
| `product` | TEXT | Not null, 1 to 100 characters, default `general` | Product id. |
| `expense_type` | TEXT | `infra`, `AI APIs`, `subscriptions`, `other`; default `other` | Kind of cost. |
| `classification_json` | TEXT | | Vendor rule ID, Clef answer, or mock marker. |
| `ai_json` | TEXT | | Raw extraction response, evidence and classification. |
| `manual_fields_json` | TEXT | Not null, default `{}` | Values typed in by you, and the approval reason and acknowledged flags. |
| `review_reasons_json` | TEXT | Not null, default `[]` | Open review flag codes. |
| `reviewed_at` | TEXT | | When it was approved. |
| `fx_eur_minor` | INTEGER | | Total converted at the ECB rate. |
| `fx_requested_date` | TEXT | | Date the rate was looked up for. |
| `eur_override_minor` | INTEGER | | Euro amount you entered. |
| `eur_override_reason` | TEXT | | Reason for it. |
| `duplicate_of` | TEXT | References `receipts(id)`; not its own `id` | The document this one duplicates. |
| `kind` | TEXT | `expense` or `sales`; default `expense` | Receipt or sales invoice. |
| `client`, `client_country`, `client_vat_id` | TEXT | | Sales invoices. |
| `vat_treatment` | TEXT | `domestic`, `reverse_charge`, `export`, `exempt` | Sales invoices. |
| `reference_number` | TEXT | | Sales invoices. |
| `paid_outside_on`, `paid_outside_note` | TEXT | | Sales invoice paid outside the bank import. |

Triggers `receipt_duplicate_insert` and `receipt_duplicate_update` abort with `duplicate_chain` when a duplicate would point at another duplicate, or a document that others point at would become a duplicate.

## `inbound_mail`

One row per email the Worker received, and every Unknown sender email that is waiting. Rows other than waiting ones are trimmed to the newest 500.

| Column | Type | Rules | Meaning |
| --- | --- | --- | --- |
| `id` | TEXT | Primary key | A random UUID. |
| `received_at` | TEXT | Not null | |
| `sender` | TEXT | At most 254 characters | The proven sender: the From address when DMARC passed for its domain, else the envelope sender. For mail that was not proven, the From address as written. |
| `envelope` | TEXT | At most 254 characters | The envelope sender. |
| `to_address` | TEXT | At most 254 characters | The address the mail was sent to. |
| `subject` | TEXT | At most 300 characters | |
| `message_id` | TEXT | At most 300 characters | The Message-ID header. Unique among waiting rows. |
| `attachments`, `size_bytes` | INTEGER | | |
| `email_key` | TEXT | | The R2 key of the stored email, when one was kept. |
| `state` | TEXT | `imported`, `held`, `ignored` or `dropped` | `held` is an email from an unknown sender, waiting in Review. |
| `reason` | TEXT | 1 to 40 characters | A reason code, such as `allowed`, `sender_not_allowed` or `sender_approved`. See [Email intake results](/reference/receipt-fields-and-flags/#email-intake-results). |

## R2 keys

All objects are in the `ORIGINALS` bucket.

| Key | Content type | Written when |
| --- | --- | --- |
| `receipts/<sha256>` | The document's media type | A document is uploaded, attached to an email, or an email body or held email is stored. `<sha256>` is the document ID. |
| `emails/<sha256>.eml` | `message/rfc822` | An email from an allowed sender passes the sender check or is held as unverified, or an email from a proven sender who is not approved is kept as Unknown sender. |
| `imports/<sha256>.csv` | `text/csv` | A bank CSV is imported. |

Objects are written once per content hash. The app deletes only the stored email of an Unknown sender item you ignore or delete, and only when no receipt uses it.
